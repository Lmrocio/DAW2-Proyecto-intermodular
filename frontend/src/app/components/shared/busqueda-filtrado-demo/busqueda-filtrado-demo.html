¿Cómo funciona?

Los datos están cargados en memoria. Los filtros se aplican instantáneamente en el cliente usando JavaScript, sin llamadas al servidor.

Ventajas:

  • Respuesta instantánea (0ms latencia)
  • Sin consumo de ancho de banda
  • Funciona offline
  • Ideal para datasets pequeños (<1000 items)

// Setup
searchControl = new FormControl('');

ngOnInit() {{'{'}}
  this.searchControl.valueChanges.pipe(
    debounceTime(300),           // Esperar 300ms después del último keystroke
    distinctUntilChanged(),      // Solo si el valor cambió
    takeUntil(this.destroy$)
  ).subscribe(term => {{'{'}}
    this.applyLocalFilters(term);
  {{'}'}});
{{'}'}}

// Filtrado
applyLocalFilters(term: string) {{'{'}}
  const searchTerm = term.toLowerCase();
  this.filtered.set(
    this.allProducts.filter(p =>
      p.name.toLowerCase().includes(searchTerm) ||
      p.description.toLowerCase().includes(searchTerm)
    )
  );
{{'}'}}

// Template con trackBy
<div *ngFor="let p of filtered(); trackBy: trackById">
  {{'{{'}} p.name {{'}}'}}
</div>

🌐 Búsqueda Remota

{{ resultCountRemote() }} resultados

¿Cómo funciona?

Cada búsqueda hace una llamada HTTP al servidor. El servidor filtra los datos y retorna solo los resultados relevantes.

Ventajas:

  • Maneja millones de registros
  • Filtros complejos (SQL, Elasticsearch)
  • Menor uso de memoria en cliente
  • Búsqueda full-text avanzada

search(term: string): Observable<Product[]> {{'{'}}
  const params = new HttpParams()
    .set('q', term)
    .set('pageSize', '20');
  return this.http.get<Product[]>('/api/products/search', {{'{'}} params {{'}'}});

// Component
results$ = this.searchControl.valueChanges.pipe(
  debounceTime(500),           // Esperar más para HTTP
  distinctUntilChanged(),
  switchMap(term =>            // Cancelar búsquedas anteriores
    this.productService.search(term)
  )
);

// Template con async pipe
<div *ngIf="results$ | async as results">

✅ Mejores Prácticas Implementadas

1️⃣ Debounce

Esperar 300-500ms después del último keystroke antes de filtrar/buscar. Evita llamadas innecesarias mientras el usuario escribe.

2️⃣ distinctUntilChanged

Solo procesar si el valor realmente cambió. Previene búsquedas duplicadas del mismo término.

3️⃣ switchMap

Cancelar búsquedas anteriores cuando llega una nueva. Evita race conditions y resultados desactualizados.

4️⃣ TrackBy

Identificar items por ID único en *ngFor. Previene flickering y mejora performance.

5️⃣ Actualizaciones Inmutables

Crear nuevos arrays en lugar de mutar. Compatible con OnPush change detection.

6️⃣ Loading States

Mostrar indicadores durante búsquedas remotas. Feedback visual claro para el usuario.
