🧭 Demostración de Navegación Programática

1. Navegación Básica

this.router.navigate(['/home'])

2. Navegación con Parámetros de Ruta

this.router.navigate(['/lecciones', 123])

3. Navegación con Query Params

this.router.navigate(['/lecciones'], { queryParams: { categoria: 'trafico', nivel: 'basico' } })

4. Navegación con Fragment (Scroll)

this.router.navigate(['/about'], { fragment: 'mision' })

5. Navegación con State (datos ocultos)

this.router.navigate(['/lecciones', 123], { state: { leccion: '...objeto...' , origen: 'demo' } })

6. NavigationExtras Completo

Incluye:
  • ✅ Parámetros de ruta (/lecciones/456)
  • ✅ Query params (?destacado=true)
  • ✅ Fragment (#comentarios)
  • ✅ State (datos en memoria)
  • ✅ Query params handling (merge)
